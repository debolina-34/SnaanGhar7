📄 About SnaanGhar7

SnaanGhar7 is the first publicly available real-world, multi-site bathroom acoustic event dataset designed for privacy-preserving ambient assisted living (AAL). The dataset contains recordings of 7 acoustic event classes from 5 real-world bathrooms (residential, hostel, and institutional environments), with 21,387 annotated audio segments collected using embedded recording platforms (Raspberry Pi Zero 2 W + WM8960 audio HAT).

Dataset Classes

Class Count Share Description
Flush 2,931 13.7% Toilet flushing - transient onset, broadband water flow

Basin Tap 3,078 14.4% Basin tap - continuous, narrow/localized flow
Door 2,688 12.6% Opening/closing/knocking - impulsive onset, short duration
Walker/Crutch 3,076 14.4% Mobility aid contact - repeated transient impacts
Unknown Class 3,225 15.1% Background/non-target events - heterogeneous class

🧠 SincDPNet: Interpretable Raw Waveform Model

The paper introduces SincDPNet, an efficient neural network architecture for bathroom acoustic event recognition on edge devices. The key innovation is a learnable sinc band-pass filter front-end where each filter is parameterized by only 2 numbers (low and high cutoff frequencies in Hz), making it highly interpretable while maintaining ultra-compact design.

🔒 Privacy & Ethical Considerations

  • ✅ Passive acoustic sensing only - No cameras
  • ✅ Activity-level classification - Not designed for speech recognition or speaker identification
  • ✅ Informed consent - All recordings collected with participant permission
  • ✅ Academic use only - Released under CC BY-NC 4.0 license
  • ✅ No PII included - Incidental speech treated as non-target noise
